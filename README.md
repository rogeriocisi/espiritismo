# Wiki Espírita

Este é um repositório estruturado como um wiki pessoal no **Obsidian**, dedicado ao estudo e sistematização do **Espiritismo**. O foco abrange a doutrina codificada por Allan Kardec, o movimento espírita brasileiro, a literatura mediúnica e os desdobramentos filosóficos e científicos da doutrina.

O objetivo principal deste projeto é acumular e interligar o conhecimento de forma organizada, permitindo uma navegação fluida entre entidades, conceitos, obras e temas transversais.

## 📂 Estrutura do Repositório

O projeto está organizado da seguinte forma:

*   **`wiki/`**: O coração do repositório, contendo as páginas de conteúdo organizadas por categoria:
    *   `autores/`: Biografias de codificadores, médiuns, pesquisadores e espíritos mentores.
    *   `conceitos/`: Princípios doutrinários, fenômenos e terminologia espírita.
    *   `obras/`: Resumos e análises de livros e séries mediúnicas.
    *   `temas/`: Discussões sobre temas transversais (ex: Reencarnação, Ciência, Caridade).
    *   `organizações/`: Informações sobre organizações e federações relevantes.
    *   `overview.md`: Uma síntese geral do estado atual do wiki.
*   **`raw/`**: Repositório de fontes brutas (PDFs e documentos originais) que servem de base para a construção do wiki.
    *   `assets/`: Imagens e mídias utilizadas nas notas.
*   **`index.md`**: Índice dinâmico e categorizado de todas as páginas existentes.
*   **`log.md`**: Histórico cronológico das operações de ingestão e atualizações significativas.
*   **`AI.md`**: Guia mestre de diretrizes e schema para a manutenção do wiki por agentes de IA.
*   **`GEMINI.md` / `CLAUDE.md`**: Arquivos de entrada específicos para agentes que apontam para o guia mestre (`AI.md`).

## 🚀 Como Utilizar

Este repositório foi otimizado para ser visualizado através do [Obsidian](https://obsidian.md/), aproveitando recursos como:

1.  **Links Internos**: Conexões entre páginas usando a sintaxe `[[Nome da Página]]`.
2.  **Frontmatter YAML**: Metadados em cada página para controle de tags, tipos e contagem de fontes.
3.  **Callouts**: Blocos especiais para destacar citações, avisos de contradições ou lacunas de conhecimento.

### Navegação Inicial
Para começar a explorar, abra o arquivo `index.md` no Obsidian ou acesse o `wiki/overview.md` para uma visão sistêmica da doutrina.

## 🛠 Manutenção e Ingestão

O wiki cresce através de um processo de **ingestão**, onde novas fontes em `raw/` são processadas para extrair conceitos e atualizar as páginas existentes. As diretrizes para esse processo estão detalhadas no arquivo `AI.md`.
